## Part 4

![image-20261020141412986](C:\Users\ziyus\AppData\Roaming\Typora\typora-user-images\image-20261020141412986.png)

If a node's secret key is stolen, an attacker can vote any value and generate a signature that can be verified successfully. The illegal message has the same signature as the legitimate ones.

The honest node cannot distinguish if a message is forged or not. As the signature is generated by a existing secret key, the verify will be successful. 

This protocol assume that the secret key is only known by the node itself so if the message is generated by the key, it will be regarded as a valid massage and the verify will be successful.

If this assumption becomes invalid, which means that an attacker get the key, a forged message which is created by the attacker will be regarded as a legal message.
